# AI向けMD計画書作成

- 思考とやることの判断はメインエージェントが担当し、タスクのMarkdownとMD計画書への書き込みはサブエージェントLunaが担当する。
- 対象の仕様と依頼内容をもとに、AIが実装に使用するMarkdown計画書を作成する。
- 作成前に[MD計画書テンプレート](../../テンプレート/IMPLEMENTATION_PLAN_TEMPLATE.md)を参照し、その構成に従って計画書を作成する。
- 計画書には、対象の要件、実装範囲、変更対象、作業手順、完了条件を記載する。
- 人間向けHTML計画書やモック画像がある場合は、それらとの整合性を保つ。
- 未確定事項は未確定と明記し、決定済みの要件と区別する。
- 対象タスクに関する要件以外は記載しない。
