# 人間向けHTML計画書作成

- 思考とやることの判断はメインエージェントが担当し、タスクのMarkdownとHTML計画書への書き込みはサブエージェントLunaが担当する。
- 対象の仕様と依頼内容をもとに、人間が読んで確認できるHTML計画書を作成する。
- 作成前に[HTML計画書テンプレート](../../テンプレート/IMPLEMENTATION_PLAN_TEMPLATE.html)を参照し、その構成に従って計画書を作成する。
- 計画書には、対象の目的、要件、画面や操作の流れ、作業内容を記載する。
- 未確定事項は未確定と明記し、決定済みの要件と区別する。
- 対象タスクに関する要件以外は記載しない。
