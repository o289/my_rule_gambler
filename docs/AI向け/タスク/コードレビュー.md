# コードレビュー

- 思考とやることの判断はメインエージェントが担当し、タスクのMarkdownとレビュー結果への書き込みはサブエージェントLunaが担当する。
- 対象コードを仕様と照合し、不具合、要件の実装漏れ、既存動作への影響を確認する。
- [コーディング規則](../ルール/coding_rule.md)を参照し、対象コードの違反を確認してレビュー結果に記載する。
- 指摘の要否と優先度はメインエージェントが判断する。
- 指摘には、該当箇所、問題の根拠、発生条件、影響を記載する。
- 修正を行う場合も、修正内容の判断はメインエージェント、コードへの書き込みはサブエージェントLunaが担当する。
- 対象タスクに関する要件以外は記載しない。
