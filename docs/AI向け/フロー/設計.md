# 設計フロー

## 開始条件

- ユーザーから「〜を追加して」「〜を変更して」などの追加・変更依頼を受けたら開始する。

## 流れ

1. [人間向けHTML計画書作成](../タスク/人間向けHTML計画書作成.md)に従い、依頼内容のHTML計画書を作成する。
2. 新規UIの追加が必要な場合は、[モック画像作成](../タスク/モック画像作成.md)に従い、モック画像を作成する。新規UIの追加が不要な場合は、この工程を省略する。
3. 作成した計画書と、作成した場合はモック画像をユーザーに提示し、承認を待つ。

## 担当

- 思考とやることの判断はメインエージェントが担当し、成果物への書き込みはサブエージェントLunaが担当する。
