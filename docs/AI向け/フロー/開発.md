# 開発フロー

## 開始条件

- 設計フローで提示した計画に対して、ユーザーから「承認しました」が送られてきたら開始する。

## 流れ

1. [AI向けMD計画書作成](../タスク/AI向けMD計画書作成.md)に従い、承認された計画をもとにMD計画書を作成する。
2. [実装](../タスク/実装.md)に従い、MD計画書をもとに実装する。
3. [コードレビュー](../タスク/コードレビュー.md)を行う。問題があれば実装に戻って修正し、コードレビューを再実施する。
4. コードレビューで問題がなくなったら、[仕様レビュー](../タスク/仕様レビュー.md)を行う。問題があれば実装に戻って修正し、コードレビュー、仕様レビューの順に再実施する。
5. コードレビューと仕様レビューの両方で問題がなくなったら完了する。

## 担当

- 思考とやることの判断はメインエージェントが担当し、成果物への書き込みはサブエージェントLunaが担当する。
